## Public Windows beta gates

1. Complete Windows 10 and 11 native comparisons, benchmark cancellation, affinity testing on a disposable process, accessibility, the remaining display scales, and one-hour profiling with recording and benchmarks. Record p95 sampling/UI times, CPU, memory, allocations, and handles; treat targets as machine-specific.
2. Repeat authorization-preserving migration against the exact final MSI and test an upgrade from this beta to the next numeric MSI version. The first candidate lost the 0.1.5 service-owned value; the revised migration preserved it in a native upgrade to an earlier candidate. The final package passed clean install, authorization, revocation, and reinstall, which are different evidence.
3. Restore GitHub Actions execution, review dependency/advisory output, approve distribution license/third-party notices, and obtain signing credentials. Unsigned installers are internal only. Define a numeric ProductVersion path from the beta MSI (`0.2.0`) to stable `0.2.0` before public release.

Features explicitly outside this cycle: process termination, priority editing, remote/cloud telemetry, automatic updates, kernel drivers, broad PMU expansion. Unsupported metrics remain unavailable with a reason.
