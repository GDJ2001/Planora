## Release gates

1. Finish and validate real PMU sampled profiling, disk ETW attribution, and vendor sensor coverage, or revise the agreed 0.3 scope before release. Preserve explicit unavailability until then.
2. Complete native Windows 10/11 measurement, accessibility, five-window-size/four-scale, 10,000-process, one-hour performance and install/repair/upgrade/uninstall matrices. Record hardware configuration and p95 times; distinguish tests from installed-system evidence.
3. Build from a clean committed revision, verify package hashes and installed UI/helper identity, observe CI execution, review dependency/advisory and license inventories, and obtain distribution signing credentials. Unsigned packages remain internal.

Process termination, priority editing, remote/cloud monitoring, automatic updates and kernel drivers remain outside this cycle. Linux and macOS packages remain previews until their own native acceptance passes.
