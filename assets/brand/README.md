# Planora brand assets

Planora is a task-management product with a blue-orbit route/destination symbol.

## Included SVG assets

| Asset | Use |
| --- | --- |
| `planora-logo-horizontal.svg` | Default light-theme header and marketing lockup |
| `planora-logo-on-dark.svg` | Header and marketing lockup on dark backgrounds |
| `planora-logo-stacked.svg` | Square marketing treatments |
| `planora-mark.svg` | Standalone symbol for interfaces |
| `planora-app-icon.svg` | Adaptive-size square app icon |
| `planora-favicon.svg` | Browser favicon |
| `planora-logo-monochrome-navy.svg` | One-color navy logo |
| `planora-logo-monochrome-white.svg` | One-color white logo on a colored background |
| `planora-social-preview.svg` | 1200 × 630 share graphic |

These SVG assets are self-contained vector adaptations of the approved blue-orbit logo concept. The approved original raster image and its pixel-accurate PNG exports were prepared separately. The SVG wordmark uses a system-font fallback stack; for brand-critical printing, convert the chosen typeface to outlines.

## Color palette

- Midnight navy: `#05255D`
- Deep blue: `#061947`
- Electric blue: `#087EFF`
- Sky cyan: `#0A9EF6`
- Teal: `#08E5C6`
- Pale surface: `#F7FBFF`

## Example usage

```html
<link rel="icon" type="image/svg+xml" href="/assets/brand/planora-favicon.svg" />
<img src="/assets/brand/planora-logo-horizontal.svg" alt="Planora" />
```

For a PWA, export the square icon to 192 × 192 and 512 × 512 PNG sizes. Keep clear space of at least 10% around the symbol. SVG logo lockups with transparent backgrounds should not be used as white text on a light background.
